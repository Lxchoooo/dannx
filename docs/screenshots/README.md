## English

This folder holds the app screenshots used in the main README.

| File | Screen |
| --- | --- |
| `explore.png` | Home feed with search, categories and tags |
| `detail.png` | Wallpaper detail with zoom and the apply/download actions |
| `collections.png` | Collections list, public and private |
| `favorites.png` | Favourites tab |

How to take them:

1. Install the latest APK from Releases on a phone or emulator.
2. Open each screen and take a full-screen screenshot.
3. Crop to the screen only (no status bar of your own device if you prefer) and
   export as PNG.
4. Name the files exactly as in the table and drop them in this folder.

Until the files exist, the README shows broken image links. That is expected.

<a id="español"></a>
## Español

Esta carpeta guarda las capturas de la app que usa el README principal.

| Archivo | Pantalla |
| --- | --- |
| `explore.png` | Feed de inicio con búsqueda, categorías y tags |
| `detail.png` | Detalle del fondo con zoom y las acciones aplicar/descargar |
| `collections.png` | Lista de colecciones, públicas y privadas |
| `favorites.png` | Pestaña de Favoritos |

Cómo sacarlas:

1. Instalá el APK más reciente de Releases en un teléfono o emulador.
2. Abrí cada pantalla y sacá una captura de pantalla completa.
3. Recortá solo la pantalla (si querés, sin la barra de estado de tu equipo) y
   exportalas en PNG.
4. Poneles los nombres exactos de la tabla y dejalas en esta carpeta.

Mientras los archivos no existan, el README muestra imágenes rotas. Es
esperado.
