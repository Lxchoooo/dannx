## DannX 1.8.0

### Preview on the lock screen

- New preview button on the wallpaper detail screen: it shows the image behind a
  simulated lock screen with the current time, today's date and a few generic
  shortcuts.
- Tap anywhere, use the close button or press Back to dismiss it. The clock
  updates while the preview is open.
- Animations are simplified in Lite mode.

### Related wallpapers

- A “You may also like” row under the apply and download actions shows up to
  five wallpapers that share tags or a category with the one you are viewing.
- The current wallpaper never appears in the row, and the row is hidden when
  there are no matches.
- Choosing a wallpaper opens its detail and replaces the current one in the back
  stack.
- The row uses what is already cached first and only asks the server when it
  needs more.

### Performance and maintenance

- New benchmark module with cold-start and feed-scroll measurements.
- Feed pagination no longer skips wallpapers, and changing the tag selection
  always starts from the first page.
- Download requests send the real app version.
- Updated dependencies, including Android Gradle Plugin 9.5.1.
- Small fixes and maintenance under the hood.
